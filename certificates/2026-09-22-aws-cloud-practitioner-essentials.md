## Overview

Completed the official AWS Cloud Practitioner Essentials course. This provides a broad foundation across the AWS Cloud, covering core services, architecture concepts, security, pricing, and the Well-Architected Framework.

---

## Modules Covered

1. **Introduction to the Cloud** — Cloud computing concepts, benefits of AWS, global infrastructure, Shared Responsibility Model  
2. **Compute** — Amazon EC2, instance types, pricing, Auto Scaling, Elastic Load Balancing, messaging/queuing  
3. **Serverless, Containers & Additional Compute** — AWS Lambda, containers and orchestration, other compute options  
4. **Global Infrastructure** — Regions, Availability Zones, edge locations, infrastructure automation  
5. **Networking** — VPC, subnets, security groups, NACLs, connectivity options, global networking  
6. **Storage** — EBS, S3 (storage classes & lifecycle), EFS, FSx, Storage Gateway, disaster recovery  
7. **Databases** — Relational (RDS), NoSQL, in-memory caching, additional database services  
8. **AI / ML & Data Analytics** — AI/ML services, generative AI on AWS, data pipelines and analytics  
9. **Security** — Identity & access, network and application protection, data protection, detection & response  
10. **Monitoring, Compliance & Governance** — CloudWatch, CloudTrail, compliance, AWS Organizations, Trusted Advisor, AWS Health  
11. **Pricing & Support** — Pricing concepts, billing tools, support plans, Marketplace, cost optimization  
12. **Migration** — Cloud Adoption Framework, 7 Rs migration strategies, migration tools and data transfer  
13. **Well-Architected Solutions** — AWS Well-Architected Framework and specialized services

## Skills Gained

- Foundational understanding of the AWS Cloud and its value proposition
