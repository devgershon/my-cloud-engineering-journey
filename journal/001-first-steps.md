# 001 – First Steps

**Date:** 18 June 2022  
**Milestone:** Completed AWS Academy Cloud Foundations

---

## What happened

I completed the AWS Academy Cloud Foundations course (20 hours) and received the Certificate of Completion + digital badge.

This was my very first formal step into cloud computing.

---

## Skills unlocked

- AWS Architecture
- AWS Cloud
- AWS Core Services
- AWS Pricing
- AWS Support

---

## How it felt

Starting something completely new. The course gave me a clear map of the AWS landscape and the confidence that I could keep going.

---

## Key takeaways

1. Cloud is not just “someone else’s computer” — it’s a completely different operating model.
2. Architecture decisions matter from day one (regions, availability, cost).
3. AWS has an enormous surface area; foundations are essential before specializing.
4. Pricing and support are first-class topics, not afterthoughts.
