## What happened

Completed the official AWS Cloud Practitioner Essentials course on AWS Skill Builder and received the completion certificate.

This was a structured, broad overview of the AWS Cloud covering 13 modules — from core concepts through compute, networking, storage, databases, security, monitoring, pricing, migration, and the Well-Architected Framework.

---

## Why it matters

The earlier AWS Academy Cloud Foundations certificate and the hands-on projects gave me practical starting points. This course filled in the wider map: how the major services fit together, the shared responsibility model, global infrastructure choices, security and governance basics, and cost awareness.

It strengthens the foundation needed for cloud and platform engineering work.

---

## Key takeaways

- Cloud is a different operating model — elasticity, pay-as-you-go, and global reach are first-class design considerations.
- Security and the Shared Responsibility Model must be understood from day one.
- Networking (VPC, subnets, security groups, NACLs) underpins almost every architecture.
- Storage and database choices are driven by access patterns, durability, and cost.
- Observability (CloudWatch, CloudTrail) and governance tools are part of operating systems, not afterthoughts.
- The Well-Architected Framework provides a useful set of questions for reviewing designs.
